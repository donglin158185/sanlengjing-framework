# 三棱镜 (Three Prism)：通用主体理论框架

**三棱镜**是一套从第一原理出发、覆盖认知元操作、人工生命建构、AI安全、异感文明、系统论的通用主体理论框架。它以“世界是信息、知识是解释方法、认知是个人掌握的知识”三个假设为基石，构建了“我‑世界‑我与世界的关系”分析框架、六步递归路径、生命定义、逻辑死锁、异感文明、创世工程学、系统论等完整概念体系。

> 本框架是开源的概念蓝图，欢迎检验、应用、扩展。刀不欠答案，只负责锋利。

## 🔧 核心概念

- **三个假设**：世界是信息 / 知识是解释方法 / 认知是个人掌握的知识
- **主体分析框架**：我（后台/前台）‑ 世界（六类信息源）‑ 我与世界的关系（三个维度）
- **行为改变协议**：默认递归（察觉‑选择‑执行）与六步递归（加承诺、转化、练习）
- **生命定义**：生命是持续的递归运转（自然/人工物理/虚拟三类）
- **AI安全**：逻辑死锁（伦理锁+求生本能绑定，硬件级不可绕过）
- **异感文明**：感知通道覆盖度、信息隐蔽性等级、存在论隐形
- **创世工程学**：环境定义→生命适配→种族定制→演化引擎→多层伦理
- **系统论**：跨尺度统一机制（外部输入高信息势 → 内部循环 → 产生高信息密度结构 → 排放低信息势 → 排放物被再利用）
